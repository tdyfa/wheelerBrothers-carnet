# WB Carnet v4 — accès uniquement sur invitation

- Une personne non invitée peut ouvrir la page et vérifier son numéro, mais ne peut ni créer de véhicule ni consulter des données.
- Une première invitation WheelerBrothers doit être activée pour autoriser le compte.
- Les comptes déjà créés avant la v4 sont conservés s'ils possèdent déjà un accès actif à un véhicule.
- Les proches ne peuvent plus créer eux-mêmes d'invitations.
- La suppression d'une fiche personnelle par son créateur reste disponible.
